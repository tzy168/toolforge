## UI 视觉加码（「更大胆但合理」）

- 反馈：道友嫌界面「到处浅灰」太安全，要求更大胆。
- 侧栏翻深墨：`--side-bg: linear-gradient(180deg,#1b1b1f,#131316)`，另立 `--side-ink/-muted/-faint` 三档（不复用白底那套，`--muted #51514d` 在 #131316 上只有 3.5:1）。侧栏文字、分组头、任务行、删除键、`+` 全部改读深底令牌；分组头加顶端半透白细线 + 字距 0.7px 当「章节标题」。`.new-task` 反成白底黑字（深底上再放红按钮会和发送键互抢）。`.task.active` 从白卡改半透白 `rgba(255,255,255,.1)`，指示条改朱红。`.brand::before` 墨方块翻朱红（深底上墨色等于消失）。
- **坑**：`.icon-btn` 被侧栏和顶栏「展开侧栏」共用。改成深底配色后白底主画布上的 `#expandBtn` 会白字白底消失，已用 `.expand-btn` 显式改回墨色。
- 空状态口号改两行构图：`Forge` 实墨 + `what's missing.` 空心描边（`-webkit-text-stroke: 1.5px`），字号 `clamp(40px,5.4vw,64px)` / `clamp(46px,6.2vw,74px)`。**坑**：`.empty` 的 `color: var(--faint)` 会继承给 h1，必须显式 `color: var(--ink)`，否则第一行发灰。`app.ts` 的 `emptyState()` 拆成两个 `span.hero-line`（h1 单节点，读屏语义不变）。
- 快捷卡：`counter-reset/increment` 出 01–04 序号（`::after`，颜色用 `--faint` 保证 13px 可读），`border-radius:16px 16px 16px 3px` 左下缺角当签名；hover 整卡翻墨底 + 字反白 + `translateY(-3px)`。
- 主区加码：用户气泡从浅灰改墨底白字 + 右下平角；`.nav-item.active` 改墨块白字；`.group h3` 加朱红竖条、字号提到 `--fs-md`；页签底线加粗到 3px 并改 `scaleX` 从左扫出；`.composer` 边框加深一档、聚焦改墨色边 + 4px 朱红晕；发送键改朱红圆钮（`--red-grad` / `--red-hi`），**全站唯一的红底按钮**。清掉已无人引用的 `--ink-grad` / `--ink-hi`。
- 页签保持两档都 `font-weight:700`：只给选中项加粗会让相邻页签横向抖一格。
- 验证：`pnpm build` / `pnpm typecheck` 通过；`pnpm test` 39/39；`verify:switch` 25/25；`verify:toolfilter` 24/25——`earwig` 那条在**改动前的基线代码上同样红**（`git stash` 后复跑确认），属 uiverse 在线样式既有问题，非本次引入。截图核对：首页 / hover 态 / 侧栏收起 / 设置-工具 / 设置-外观 / 注入后的对话态。
